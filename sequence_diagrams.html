Sequence Diagrams

IntelliPortfolio — AI-Powered Portfolio Optimization System

ไดอะแกรมด้านล่างนี้ครอบคลุม ทุก Flow ของระบบ IntelliPortfolio ตั้งแต่การล็อกอิน, การคำนวณ AI Engine, จนถึงระบบจัดการหลังบ้าน (Admin)

1. Authentication & Role-Based Access Control (RBAC)

1.1 การล็อกอินและเข้าสู่ระบบ

sequenceDiagram
    autonumber
    actor User as ผู้ใช้งาน
    participant Browser as Next.js Frontend
    participant Clerk as Clerk Auth Service
    participant Middleware as Next.js Middleware
    participant Page as Protected Page

    User->>Browser: เข้า URL (e.g., /dashboard)
    Browser->>Middleware: Request /dashboard
    Middleware->>Clerk: ตรวจสอบ Auth Token
    
    alt ยังไม่ได้ล็อกอิน
        Clerk-->>Middleware: ไม่พบ Token
        Middleware-->>Browser: Redirect → /login
        Browser-->>User: แสดงหน้า Login
        User->>Browser: กรอก Email / Password
        Browser->>Clerk: Sign In Request
        Clerk->>Clerk: ตรวจสอบข้อมูล
        Clerk-->>Browser: Auth Token + Session Cookie
        Browser->>Middleware: Request /dashboard (with Cookie)
    end
    
    Middleware->>Clerk: Verify Token
    Clerk-->>Middleware: Valid ✅ (userId)
    Middleware-->>Page: อนุญาตเข้าถึง
    Page-->>Browser: Render หน้าเว็บ
    Browser-->>User: แสดงหน้า Dashboard

1.2 การเข้าถึงหน้า Admin (RBAC Check)

sequenceDiagram
    autonumber
    actor Admin as ผู้ใช้งาน
    participant Browser as Admin Page (React)
    participant ClerkHook as useAuth() Hook
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL

    Admin->>Browser: เข้าหน้า /admin
    Browser->>ClerkHook: ดึง userId
    ClerkHook-->>Browser: userId

    alt ไม่มี userId
        Browser-->>Admin: แสดง Access Denied
    end

    Browser->>FastAPI: GET /api/users/{userId}/role
    FastAPI->>DB: SELECT role FROM users WHERE clerk_id = ?
    
    alt พบ User ในระบบ
        DB-->>FastAPI: role = admin
    else ไม่พบ User
        DB-->>FastAPI: empty
        FastAPI-->>Browser: role = user (default)
    end
    
    FastAPI-->>Browser: { status: success, role: admin }
    
    alt role = admin หรือ analyst
        Browser->>Browser: setIsAdminAuthenticated(true)
        Browser->>FastAPI: ดึงข้อมูล Users + Assets
        Browser-->>Admin: แสดง Admin Console
    else role = user
        Browser-->>Admin: แสดง Access Denied
    end

2. Portfolio Optimization (AI Engine — Core Flow)

2.1 การวางแผนและสร้างพอร์ต (Full Pipeline)

sequenceDiagram
    autonumber
    actor User as ผู้ใช้งาน
    participant PlanPage as Plan Page
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL
    participant DataFetcher as SETDataFetcher
    participant Yahoo as Yahoo Finance
    participant BL as Black-Litterman
    participant GA as Genetic Algorithm
    participant Views as ViewProvider
    participant Backtest as BacktestEngine
    participant Redis as Redis Cache

    User->>PlanPage: กรอกข้อมูลการลงทุน
    Note over PlanPage: ชื่อพอร์ต, งบประมาณ, เป้าหมาย,
ระดับความเสี่ยง, จำนวนหุ้น,
น้ำหนักสูงสุด, หุ้นล็อค

    PlanPage->>FastAPI: POST /api/optimize

    rect rgb(230, 240, 255)
        Note over FastAPI,Redis: Step 1: ดึงรายชื่อหุ้น SET50
        FastAPI->>DataFetcher: get_set50_tickers()
        DataFetcher->>DB: SELECT ticker FROM assets WHERE is_active = TRUE
        DB-->>DataFetcher: tickers 50 ตัว
        DataFetcher-->>FastAPI: tickers[]
    end

    rect rgb(230, 255, 230)
        Note over FastAPI,Yahoo: Step 2: ดึงราคาหุ้นและคำนวณ Beta
        FastAPI->>Yahoo: get_market_data_with_beta(tickers)
        Yahoo->>Redis: ตรวจสอบ Cache
        alt มี Cache
            Redis-->>Yahoo: คืน cached data
        else ไม่มี Cache
            Yahoo->>Yahoo: Download via yfinance
            Yahoo->>Redis: บันทึก Cache (TTL 6 ชม.)
        end
        Yahoo-->>FastAPI: cov_matrix, betas
    end

    rect rgb(255, 240, 230)
        Note over FastAPI,DB: Step 3: ดึง Market Cap
        FastAPI->>DataFetcher: get_market_caps(valid_tickers)
        DataFetcher->>DB: SELECT ticker, market_cap FROM assets
        DB-->>DataFetcher: market_caps
        DataFetcher-->>FastAPI: market_caps (pd.Series)
    end

    rect rgb(255, 255, 230)
        Note over FastAPI,Views: Step 4: เตรียม Analyst Views
        FastAPI->>Views: get_all_views(valid_tickers)
        Views->>DB: SELECT * FROM analyst_views
        DB-->>Views: มุมมองนักวิเคราะห์
        Views-->>FastAPI: views_data
        Note over FastAPI: ผสาน user_custom_views (ถ้ามี)
    end

    rect rgb(230, 245, 255)
        Note over FastAPI,BL: Step 5: Black-Litterman Model
        FastAPI->>BL: calculate_posterior()
        Note over BL: Prior Returns จาก Market Equilibrium
ผสาน Views ด้วย Bayesian Update
        BL-->>FastAPI: adj_returns, updated_cov
    end

    rect rgb(245, 230, 255)
        Note over FastAPI,GA: Step 6: Genetic Algorithm
        FastAPI->>GA: run_optimization()
        Note over GA: Population 200 ชุด
        loop 100 Generations
            GA->>GA: Selection, Crossover, Mutation
        end
        GA-->>FastAPI: portfolio_df, final_ret, final_vol
    end

    rect rgb(240, 240, 230)
        Note over FastAPI,DB: Step 7: บันทึกลง Database
        FastAPI->>FastAPI: calculate_success_probability()
        FastAPI->>FastAPI: calculate_forecast_range()
        FastAPI->>DB: UPSERT users + INSERT portfolios
        DB-->>FastAPI: portfolio_id
        FastAPI->>DB: INSERT portfolio_assets
    end

    rect rgb(230, 240, 240)
        Note over FastAPI,Backtest: Step 8: Backtest ย้อนหลัง
        FastAPI->>Backtest: run_backtest(weights, start, end)
        Backtest->>Yahoo: ดึงราคาย้อนหลัง
        Yahoo-->>Backtest: Historical prices
        Backtest-->>FastAPI: bt_results
    end

    FastAPI-->>PlanPage: Response JSON
    PlanPage->>PlanPage: Redirect to /dashboard/{id}
    PlanPage-->>User: แสดงผลลัพธ์พอร์ต

3. Portfolio Dashboard

3.1 ดูรายการพอร์ตทั้งหมด

sequenceDiagram
    autonumber
    actor User as ผู้ใช้งาน
    participant Dashboard as Dashboard Page
    participant ClerkHook as useAuth()
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL

    User->>Dashboard: เข้าหน้า /dashboard
    Dashboard->>ClerkHook: ดึง userId
    ClerkHook-->>Dashboard: userId
    Dashboard->>FastAPI: GET /api/portfolios?clerk_id={userId}
    FastAPI->>DB: SELECT * FROM portfolios WHERE clerk_id = ? ORDER BY created_at DESC
    DB-->>FastAPI: rows[]
    
    loop แต่ละพอร์ต
        FastAPI->>FastAPI: calculate_success_probability()
        FastAPI->>FastAPI: calculate_forecast_range()
    end
    
    FastAPI-->>Dashboard: { portfolios: [...] }
    Dashboard-->>User: แสดงรายการพอร์ตทั้งหมด

3.2 ดูรายละเอียดพอร์ตเฉพาะตัว + Backtest

sequenceDiagram
    autonumber
    actor User as ผู้ใช้งาน
    participant Detail as Dashboard/{id} Page
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL
    participant Backtest as BacktestEngine
    participant Yahoo as Yahoo Finance API

    User->>Detail: เข้าหน้า /dashboard/{portfolio_id}
    Detail->>FastAPI: GET /api/portfolios/{portfolio_id}
    
    FastAPI->>DB: SELECT * FROM portfolios WHERE id = ?
    DB-->>FastAPI: portfolio metadata
    FastAPI->>DB: SELECT * FROM portfolio_assets WHERE portfolio_id = ?
    DB-->>FastAPI: assets (ticker, weight, beta)
    
    FastAPI->>FastAPI: คำนวณ success_probability + forecast_range
    
    FastAPI->>Backtest: run_backtest(weights_dict, start, end)
    Backtest->>Yahoo: ดึงราคาย้อนหลังตาม duration
    Yahoo-->>Backtest: Historical data
    Backtest->>Backtest: คำนวณ NAV, Drawdown, Sharpe Ratio
    Backtest-->>FastAPI: backtest results
    
    FastAPI-->>Detail: { metadata, portfolio[], backtest }
    Detail-->>User: แสดงกราฟ Backtest, Pie Chart, ตาราง

4. Admin — จัดการผู้ใช้งาน (User Role Management)

4.1 ดูรายชื่อผู้ใช้งานทั้งหมด

sequenceDiagram
    autonumber
    actor Admin as Admin
    participant AdminPage as Admin Page
    participant NextAPI as Next.js API Route
    participant Clerk as Clerk Backend SDK
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL

    Admin->>AdminPage: กดแท็บ Users
    AdminPage->>AdminPage: getToken() จาก useAuth()
    
    par ดึงข้อมูลพร้อมกัน
        AdminPage->>NextAPI: GET /api/admin/users (Bearer token)
        NextAPI->>NextAPI: await auth() ตรวจสอบ userId
        NextAPI->>FastAPI: GET /api/admin/users
        FastAPI->>DB: SELECT clerk_id, role, COUNT(portfolios) FROM users
        DB-->>FastAPI: DB users[]
        FastAPI-->>NextAPI: { data: dbUsers[] }
        NextAPI->>Clerk: getUserList()
        Clerk-->>NextAPI: Clerk users[] (ชื่อ, email, รูป)
        NextAPI->>NextAPI: Merge Clerk + DB data
        NextAPI-->>AdminPage: { data: mergedUsers[] }
    and
        AdminPage->>FastAPI: GET /api/admin/assets
        FastAPI->>DB: SELECT * FROM assets
        DB-->>FastAPI: assets[]
        FastAPI-->>AdminPage: { data: assets[] }
    end
    
    AdminPage-->>Admin: แสดงตาราง Users พร้อมข้อมูลครบ

4.2 เปลี่ยน Role ผู้ใช้งาน

sequenceDiagram
    autonumber
    actor Admin as Admin
    participant AdminPage as Admin Page
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL

    Admin->>AdminPage: เลือก Role ใหม่จาก Dropdown
    AdminPage->>AdminPage: confirm ยืนยันการเปลี่ยนสิทธิ์
    Admin->>AdminPage: กด OK

    AdminPage->>FastAPI: PUT /api/admin/users/{target_id}/role
    Note over AdminPage,FastAPI: { new_role: admin, admin_id: user_abc123 }

    FastAPI->>DB: SELECT role FROM users WHERE clerk_id = admin_id
    DB-->>FastAPI: role = admin
    
    alt ผู้ร้องขอไม่ใช่ Admin
        FastAPI-->>AdminPage: { status: error, Unauthorized }
        AdminPage-->>Admin: แสดง Alert แจ้งเตือน
    end

    FastAPI->>DB: UPSERT users SET role = admin
    DB-->>FastAPI: Updated
    FastAPI-->>AdminPage: { status: success }
    AdminPage->>AdminPage: fetchAdminData() Reload
    AdminPage-->>Admin: ตาราง Refresh แสดง Role ใหม่

6. Landing Page — Market Highlights

sequenceDiagram
    autonumber
    actor Visitor as ผู้เยี่ยมชม
    participant Landing as Landing Page
    participant FastAPI as FastAPI Backend
    participant Cache as In-Memory Cache
    participant Yahoo as Yahoo Finance API

    Visitor->>Landing: เข้า URL / (หน้าแรก)
    Landing->>FastAPI: GET /api/market-highlights

    FastAPI->>Cache: ตรวจสอบ Cache
    
    alt มี Cache (อายุน้อยกว่า 1 ชม.)
        Cache-->>FastAPI: cached data
        FastAPI-->>Landing: { data: [...], cached: true }
    else ไม่มี Cache หรือหมดอายุ
        loop DELTA, SCC, PTTEP
            FastAPI->>Yahoo: yf.download(symbol, 21 วันก่อน)
            Yahoo-->>FastAPI: Historical price data
            FastAPI->>FastAPI: คำนวณ change, pct_change
        end
        FastAPI->>Cache: บันทึก Cache (TTL 1 ชม.)
        FastAPI-->>Landing: { data: [...], cached: false }
    end

    Landing-->>Visitor: แสดง Market Highlight Cards

7. ภาพรวม Architecture (System Overview)

sequenceDiagram
    autonumber
    participant User as User Browser
    participant Next as Next.js (Port 3000)
    participant Clerk as Clerk Auth
    participant API as FastAPI (Port 8000)
    participant DB as PostgreSQL (Port 5432)
    participant Redis as Redis (Port 6379)
    participant Yahoo as Yahoo Finance

    Note over User,Yahoo: ระบบทั้งหมดรันบน Docker Compose

    User->>Next: HTTP Request
    Next->>Clerk: ตรวจสอบ Authentication
    Clerk-->>Next: userId / Session
    
    Next->>API: Proxy API Calls
    API->>DB: Read/Write Data
    API->>Redis: Cache Market Data
    API->>Yahoo: Fetch Stock Prices
    
    Yahoo-->>API: Price Data
    Redis-->>API: Cached Data
    DB-->>API: Query Results
    API-->>Next: JSON Response
    Next-->>User: Rendered Page + Data

สรุปตาราง API Endpoints

Method Endpoint หน้าที่ ใช้ใน
