**อ้างอิงตรงตาม Use Case Diagram ต้นแบบ ทั้ง 15 Use Cases และยึดมาตรฐาน UML (ไม่มี Swimlane DB)**

## 1. การสมัครสมาชิก (Register)
```plantuml
@startuml
skinparam ranksep 50
|User|
start
-->
:เข้าสู่หน้าสมัครสมาชิก;
:กรอกข้อมูลส่วนตัวและรหัสผ่าน;
:กดยืนยันการสมัครสมาชิก;
|หน้าสมัครสมาชิก : Website|
:ส่งข้อมูลการสมัคร (POST /register);
|backend : API|
:ตรวจสอบความถูกต้องของข้อมูล;
if (ข้อมูลถูกต้องและไม่ซ้ำ?) then (ใช่)
  :บันทึกข้อมูลผู้ใช้งานใหม่ลงฐานข้อมูล;
  :ส่งสถานะสำเร็จ (201 Created);
  |หน้าสมัครสมาชิก : Website|
  :แสดงข้อความสมัครสมาชิกสำเร็จ\nและพาไปหน้า Login;
  |User|
  stop
else (ไม่ใช่)
  |backend : API|
  :ส่งสถานะผิดพลาด (400 Bad Request);
  |หน้าสมัครสมาชิก : Website|
  :แสดงข้อความเตือนให้แก้ไขข้อมูล;
  |User|
  stop
endif
@enduml
```

## 5. การสร้างพอร์ตการลงทุน (Create Investment Portfolio)
```plantuml
@startuml
skinparam ranksep 50
|User|
start
-->
:เข้าสู่หน้าสร้างพอร์ตการลงทุน;
:เลือกเงื่อนไขคำนวณพอร์ต (เงินลงทุน/เวลา/ความเสี่ยง);
:กด "ประมวลผลและสร้างพอร์ต";
|หน้าสร้างพอร์ต : Website|
:ส่งพารามิเตอร์การจัดพอร์ต (POST /portfolio/create);
|backend : API|
:ตรวจสอบข้อมูล และดึงประวัติราคาหุ้น SET50 จากฐานข้อมูล;
:ส่งพารามิเตอร์ให้โมเดลประมวลผล;
|engine : Model|
:ประมวลผล Black-Litterman และ Genetic Algorithm (GA);
if (ประมวลผลสำเร็จและได้ผลลัพธ์?) then (ใช่)
  :คำนวณหาสัดส่วนการลงทุนและผลตอบแทนคาดหวัง;
  |backend : API|
  :สร้างและบันทึกโครงสร้างพอร์ตการลงทุนลงฐานข้อมูล;
  :ส่งข้อมูลพอร์ตการลงทุนกลับมา;
  |หน้าสร้างพอร์ต : Website|
  :แสดงผลลัพธ์พอร์ตการลงทุนและสัดส่วนหุ้นบนหน้าจอ;
  |User|
  stop
else (ไม่ใช่/โมเดลล้มเหลว)
  |backend : API|
  :ส่งสถานะข้อผิดพลาดการประมวลผล;
  |หน้าสร้างพอร์ต : Website|
  :แสดงข้อความแจ้งเตือนไม่สามารถจัดพอร์ตได้;
  |User|
  stop
endif
@enduml
```
