# คำอธิบาย Class Diagram (ฉบับย่อ)

**ภาพที่ 3.3x Class Diagram ของระบบวางแผนการลงทุนอัจฉริยะสำหรับหลักทรัพย์กลุ่ม SET50 โดยใช้แบบจำลอง Black-Litterman และ Genetic Algorithm**

Class Diagram ดังภาพที่ 3.3x อธิบายโครงสร้างเชิงโครงสร้างและการทำงานของระบบจัดพอร์ตลงทุนอัจฉริยะ ประกอบด้วยคลาส Member ซึ่งเป็นคลาสแม่ในการสืบทอดคุณสมบัติให้แก่คลาสลูก ได้แก่ User (ผู้ใช้งานทั่วไป) และ Admin (ผู้ดูแลระบบที่มีสิทธิ์จัดการคลาส Asset สำหรับข้อมูลหุ้น SET50) สำหรับการจัดพอร์ตจะใช้คลาส Portfolio ในการเก็บและกำหนดค่าพอร์ตลงทุน เชื่อมโยงแบบหนึ่งต่อหนึ่งกับคลาส Dashboard เพื่อนำสัดส่วนหุ้นและผลการวิเคราะห์มาแสดงผลและส่งออกรายงาน PDF ส่วนรายการสินทรัพย์จะใช้คลาส PortfolioAsset เป็นตัวแทนกำหนดน้ำหนักการลงทุนของแต่ละหุ้น และคลาส StockView เป็นตัวแทนกำหนดมุมมองการลงทุน (Views) ในแบบจำลอง Black-Litterman ซึ่งทั้งสองคลาสมีความสัมพันธ์แบบ Composition ร่วมกับคลาส Portfolio (เมื่อลบพอร์ต ข้อมูลสินทรัพย์ย่อยและมุมมองจะถูกลบไปด้วย) และอ้างอิงข้อมูลหุ้นไปยังคลาส Asset โดยคลาส Portfolio จะเรียกใช้และพึ่งพา (Dependency) คลาส BacktestEngine ในการทดสอบย้อนหลัง และคลาส OptimizationEngine ในการประมวลผลคำนวณสัดส่วนพอร์ตที่เหมาะสมที่สุดผ่านแบบจำลอง Black-Litterman และ Genetic Algorithm
