# รายละเอียดคำอธิบาย Use Case (Use Case Description)

เอกสารนี้แสดงคำอธิบายรายละเอียด Use Case ของระบบการจัดการพอร์ตการลงทุนอัจฉริยะโดยใช้อัลกอริทึมเชิงพันธุกรรม (Intelliportfolio Management System Using Genetic Algorithms) จำนวน 15 Use Case ตามตารางมาตรฐาน

---

### ตารางที่ 3.1 Use Case Diagram: สมัครสมาชิก

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **Use Case Diagram** | **( สมัครสมาชิก )** |
| **System** | สมัครสมาชิก (Register) |
| **Actor** | User |
| **วัตถุประสงค์** | เพื่อลงทะเบียนสร้างบัญชีผู้ใช้งานสำหรับเข้าถึงระบบจัดการพอร์ตการลงทุน |
| **ผลการดำเนินการ** | ระบบบันทึกข้อมูลและสร้างบัญชีผู้ใช้งานสำเร็จ พร้อมสำหรับการเข้าใช้งาน |
| **ขั้นตอนการดำเนินงาน** | 1. ผู้ใช้งานเข้าสู่หน้าต่างสมัครสมาชิก<br>2. ระบุข้อมูลส่วนบุคคลและกำหนดรหัสผ่าน<br>3. กดยืนยันการสมัครสมาชิก<br>4. ระบบตรวจสอบความถูกต้องและบันทึกข้อมูลลงสู่ฐานข้อมูล |

### ตารางที่ 3.6 Use Case Diagram: สร้างพอร์ตการลงทุน

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **Use Case Diagram** | **( สร้างพอร์ตการลงทุน )** |
| **System** | สร้างพอร์ตการลงทุน (Create Investment Portfolio) |
| **Actor** | User |
| **วัตถุประสงค์** | เพื่อส่งพารามิเตอร์เป้าหมายและข้อกำหนดการเลือกหุ้นเข้าไปประมวลผลด้วยโมเดล Black-Litterman และ Genetic Algorithm เพื่อสร้างสัดส่วนพอร์ตที่เหมาะสมที่สุด (Optimal Portfolio) |
| **ผลการดำเนินการ** | พอร์ตการลงทุนได้รับการสร้างและบันทึกสัดส่วนสินทรัพย์ลงสู่ระบบสำเร็จ พร้อมแสดงผลการทดสอบย้อนหลัง (Backtest) |
| **ขั้นตอนการดำเนินงาน** | 1. ผู้ใช้งานคลิกปุ่ม "วิเคราะห์และสร้างพอร์ต"<br>2. ระบบส่งเงื่อนไขและมุมมองที่ผู้ใช้กำหนดไปยัง backend API<br>3. โมเดลประมวลผลดึงข้อมูลราคาและสถิติจาก DB จากนั้นรัน Black-Litterman และ GA เพื่อวิเคราะห์สัดส่วนที่เหมาะสมที่สุด<br>4. ระบบบันทึกพอร์ตที่วิเคราะห์แล้ว และแสดงผลลัพธ์พอร์ตการลงทุนพร้อมสถิติบนหน้าเว็บ |

| **ผลการดำเนินการ** | สิทธิ์ในการเข้าถึงระบบของผู้ใช้ถูกลบ และถูกนำทางกลับไปยังหน้าแรกของเว็บไซต์ในสถานะไม่ได้ล็อกอิน |
| **ขั้นตอนการดำเนินงาน** | 1. ผู้ใช้งาน/ผู้ดูแลระบบกดปุ่ม "ออกจากระบบ"<br>2. ระบบเคลียร์และลบ Token การเข้าถึง (JWT) ออกจากหน่วยความจำหรือ Local Storage ของเบราว์เซอร์<br>3. เปลี่ยนเส้นทาง (Redirect) เพื่อเข้าสู่หน้าหลักของแอปพลิเคชัน |
